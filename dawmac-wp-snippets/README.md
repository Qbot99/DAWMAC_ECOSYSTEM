# Snippety WPCode z dawmac.pl

Kod tych snippetów żył wyłącznie w bazie produkcyjnej, bez historii zmian.
Ten katalog jest kopią odniesienia — źródłem prawdy pozostaje WPCode w WordPressie.

**Uwaga przy edycji przez WP-CLI:** WPCode trzyma skompilowany kod w opcji
`wpcode_snippets`. Zapis `post_content` jej NIE odświeża, a skasowanie opcji
wyłącza wszystkie snippety. Trzeba podmienić pola `code` i `compiled_code`
w tej opcji dla danego id.
